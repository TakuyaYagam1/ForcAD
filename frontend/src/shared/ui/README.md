# Shared UI

Use this directory for visual components shared across pages and features.

- `backgrounds/` contains page backgrounds.
- `brand/` contains the app icon, page hero, rank badge, team avatar, event
  summary, score, statistic, and service-status components.
- `layout/` contains the app shell.

For generic controls, use the base components in
[components/ui](../../components/ui/README.md). Keep page or domain-specific
behavior with the feature or entity that owns it.
