`install.sh` applies the generated interface and sysctl settings, loads the
ForcAD firewall, and enables and starts both WireGuard tunnels. It restarts
`networking.service` only when the live address or default route differs.

Run `bash test.sh` after installation. Keep console access available because a
network restart can interrupt SSH. If installation reports a failure, it tries
to restore the files and live state and reports any recovery problem.

Forward UDP/56767 and UDP/56768 from the external gateway to the router WAN IP
(use the configured ports if different). Verify a client handshake from
outside with `wg show`.
